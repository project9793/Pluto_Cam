Setup: go live over the internet (Firebase + GitHub Pages)
  1. Create a Firebase project and enable Realtime Database (and Anonymous Auth if you want rules-based access).
  2. Copy your web config into the FIREBASE_CONFIG object at the top of this file's script.
  3. Enable Authentication → Sign-in method → Anonymous, then set rules so only authenticated users may read/write liveSessions/<id>.
  4. Add optional TURN credentials to ICE_SERVERS for networks where STUN fails.
  5. Host this single file on GitHub Pages over HTTPS (camera + WebRTC need a secure context).
  6. Open the page on the TV, switch to Watch, enter the code. On the phone, switch to Broadcast and Start Live.

Until Firebase is configured, the app runs in Local test mode: two tabs of this same page in one browser connect to each other - perfect for verifying the flow with zero setup.
